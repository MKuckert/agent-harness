# Research Notes

Durable research notes written by the **Librarian** (dispatched by the Orchestrator via `/research`).

- One file per topic, normalized filename assigned by the Orchestrator.
- Note format: topic, date, scope, conclusions, source URLs with version context, uncertainty, and `Status:` (`complete` / `partial` / `failed`).
- Existing files are never overwritten without an explicit update request.
- Verification of findings is tracked separately (issue #85).
